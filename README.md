# Field Notes From the Blue

An expandable collection of short, interactive, illustrated documentaries about sea animals.

**Volume I: _Whale Sharks: In the Company of Gentle Giants_**

> Whale sharks are my favorite animals because they are gentle giants: immense, peaceful, and quietly extraordinary.

Each volume is a six-chapter field journal that takes about five minutes to explore:

1. The journal opens above the water.
2. An illustrated encounter with the animal, with scale references.
3. An interactive anatomy plate and one behavior, modelled.
4. A hands-on version of a real research method.
5. The evidence: a map, what is known, what is not, and how to help.
6. The collection: what comes next.

Everything runs in the browser, with no accounts, API keys, trackers or paid services.

## Principles

- **Every fact is cited.** Claims link to peer-reviewed papers, IUCN assessments and agency sources. Each source is checked independently before it ships.
- **Illustration is labeled as illustration.** Artwork, motion and simplified maps are marked as illustrative, never passed off as data.
- **Accessible from the start.** It supports keyboard navigation, screen readers, touch, reduced motion and small screens.
- **Ask the Field Journal is not a chatbot.** It is a small local assistant that answers only from cited notes stored in the page, and says so when it has no answer.
